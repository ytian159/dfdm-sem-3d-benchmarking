# DFDM Mesh

`mesh_bricks.txt.xz` is the DFDM3D production mesh for AK135-F with a 50 km deep source: 66,560 elements in 22 radial layers, with 8, 16 or 32 elements per chunk edge depending on depth, and the deep layers merged into taller elements. `scripts/stage_cases.py` decompresses it into each DFDM case and checks it against `SHA256SUMS`.

It was generated by the DFDM3D mesh planner (`automesh/` in the `production-2026-10` branch):

```bash
python3 -s -m automesh build --preset ak135-rungc-p4 --tall-elements --source-region freeze \
  --unhonored-interfaces freeze --base-toml <DFDM config with the source> --workdir <dir> \
  --solver <dfdm_elastic3d> --omp 16
```

The radial point counts, including the 5-point crust, are set in the DFDM configuration (`nz_per_layer`, `allow_low_radial_order`), not in the mesh file. A source at another depth needs its own mesh and a new stability check of the time step.
